# Security policy

Please do not disclose a suspected security vulnerability in a public issue.
Use **Report a vulnerability** from the repository's Security tab when that
private reporting flow is available. Include the affected version, macOS
version, media type, impact, and the smallest safe reproduction you can
provide. If the private form is unavailable, open a public issue containing no
vulnerability details and ask the maintainers to provide a private contact
channel.

Security fixes are prepared privately and released after a supported version
has been updated. General crashes, playback failures, and feature requests may
use the public issue tracker.
